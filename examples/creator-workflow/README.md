# Creator Workflow Companion — code-first PBS Studio plugin

This is a **real Python source project** that builds a fully validated PBS
Studio v3 extension. It helps stream operators prepare a console session and
wrap up a broadcast, with two clickable runbook cards, two navigation
shortcuts, safe Twitch/YouTube RTMPS endpoint templates and four host-event
notifications. No stream key is included or accessed by the plugin.

Run from the **root of PBS-SDK** (Python 3.10+):

```sh
python -m pip install -r requirements-dev.txt
python examples/creator-workflow/build.py
python scripts/validate.py examples/creator-workflow/dist/plugin.json
python -m unittest discover -s tests -p 'test_*.py'
```

To build a smaller custom workflow entirely through **Python code/config**:

```sh
python examples/creator-workflow/build.py --profile quick --platform twitch \
  --output examples/creator-workflow/dist/twitch.json \
  --demo-event broadcast.started
```

The source contains real conditional configuration and reusable typed SDK
calls (`Plugin.card`, `.shortcut`, `.stream_preset`, `.on`). The generated
`dist/plugin.json` is deterministic and checked against the same v3 public
contract as every other PBS Studio plugin. Edit `build.py` and rebuild to
change the capabilities; version upgrades require review in PBS Studio.

## Installing the result

On a **desktop** PBS Studio build with plugin support enabled, open
**Settings → Plugins → Review manifest**, select `dist/plugin.json`, verify
the requested permissions and select **Approve and install**. Revoke grants
or disable the plugin individually at any time. Start from a real console
connection or broadcast transition: startup state does not generate toasts.

The `dist/` file is a deployment artifact; it is intentionally generated by
the developer and **is the only file PBS Studio imports**. Python executes at
**build time only**, on the developer's machine. PBS Studio does **not**
execute this Python source, cannot execute arbitrary plugin hooks and does not
host a WASM sandbox yet. Runtime-programmable plugins require a separately
designed and verified isolation boundary; this example does not pretend
otherwise.
